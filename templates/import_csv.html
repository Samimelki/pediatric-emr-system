Import CSV Data

Import patient data from CSV files exported from this system or other EMR systems.

Import Instructions
Supported File Types:
  • patients.csv - Patient demographic data
  • visits.csv - Visit records and measurements
  • immunizations.csv - Vaccination records
Import Options:
  • Single File: Upload one CSV file at a time
  • Bundle Import: Upload multiple CSV files together
  • Update Mode: Choose whether to update existing records or skip duplicates
File Format Requirements:
  • UTF-8 encoding with BOM (for French characters: é, è, à, ù, etc.)
  • CSV format with comma separators
  • First row must contain column headers
  • Date format: YYYY-MM-DD or DD/MM/YYYY
Tip: Files exported from this system are already in the correct format and can be re-imported directly.
Upload CSV Files
You can select multiple CSV files for bundle import. Supported files: patients.csv, visits.csv, immunizations.csv
Import Options
If checked, existing records will be updated with new data. If unchecked, duplicate records will be skipped.
Warning: This will completely replace your current database with the imported data.
Choose whether to generate patient documents after import. Documents are saved to Documents/UnifiedEMR/word_documents/
Important Notice:
  • This operation will import data into your current database
  • Make sure to backup your database before importing large datasets
  • Import order: Patients → Visits → Immunizations (for referential integrity)
  • French accented characters (é, è, à, ù, î, ï) are fully supported
