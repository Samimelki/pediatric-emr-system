Configuration Information
How Configuration Works:
  • User Config: ~/Documents/UnifiedEMR/user_config/vaccine_schedule_config.json
  • Fallback: vaccine_schedule_config.json (in app directory)
  • Factory Reset: Restores default vaccine schedules and name mappings
  • Backups: Automatically created before factory reset, or manually
Name Mappings:

The configuration includes name mappings to handle vaccine name variations:

  • "Measles" → "Measles (Single)"
  • "Measles - Mumps - Rubella (MMR)" → "MMR (Measles, Mumps, Rubella)"
  • "Haemophilus influenzae type b (Hib)" → "Hib (Haemophilus influenzae b)"
